# Top-20 SEO Optimisation Framework

## Required Google Search Console export

Export the previous 90 days at page level with: URL, clicks, impressions, CTR, average position, country, device, and query. Filter to India where appropriate.

## Selection method

Prioritise commercial-intent pages with meaningful impressions, low CTR, and average positions between 8 and 15. Exclude noindex pages, thin archives, canonical duplicates, and pages without a clear conversion path.

## Review safeguards

- Retain URLs unless a documented technical reason and redirect plan exist.
- Compare current metadata before proposing changes.
- Do not force a query into a page where it does not match the user intent.
- Validate title/description uniqueness against the published sitemap before release.
- Record a before/after date to assess Search Console changes after deployment.
